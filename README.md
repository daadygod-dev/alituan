## 👋 About Me

I'm a solo full-stack developer and founder of **Vertex Technology Services**, based in Kigali, Rwanda. I build web platforms, mobile apps, and SaaS products — usually with an eye on solving real problems for the Rwandan and East African market.

- 🔭 Currently building **ShiftWise** — a shift-worker utility app in React Native / Expo
- 🌍 Focused on Rwanda-first products: marketplaces, fintech tools, and school management systems
- 🛠️ I favor deliberate, craftsman-level decisions over generic defaults — no cargo-culting
- 📈 Progressively leveling up since 2024 — from static sites to full production SaaS
- ⚡ Fun fact: I pair AI tools with my own skill-building instead of blind delegation
